## 🌟 Overview

**Coding Meet Portfolio** is an agency-grade personal developer website built with **Kotlin**, **Compose HTML**, and **Kobweb**. Designed with modern glassmorphism, responsive ambient aurora backgrounds, interactive maps, and deep-linking architecture, it highlights production mobile applications, Kotlin Multiplatform software, client services, technical articles, and social proof.

---

## 🚀 Getting Started

### Prerequisites:

- [Java Development Kit (JDK 17+)](https://adoptium.net/)
- [Kobweb CLI](https://kobweb.varabyte.com/docs/getting-started/getting-kobweb)

### Local Development:

```bash
# 1. Clone the repository
git clone https://github.com/Coding-Meet/Porfolio-Kobweb.git
cd Porfolio-Kobweb

# 2. Run the Kobweb dev server
cd site
kobweb run
```

Open [http://localhost:8080](http://localhost:8080) in your browser.

---

## 🚢 Deployment (Firebase Hosting)

```bash
# 1. Build and export static site (automatically injects Open Graph preview tags for all projects, services & blogs)
cd site && kobweb export --layout static

# 2. (Optional) Verify all 56 pages and preview images
cd .. && python3 scripts/verify_images.py

# 3. Deploy to Firebase Hosting
firebase deploy
```
